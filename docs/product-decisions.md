# DayFrame 제품 결정 기록

## 확정한 방향

- Android를 먼저 출시하고, iPhone 확장을 고려해 Expo 기반 React Native와 TypeScript를 사용한다.
- 기록 질문은 `지난 한 시간, 주로 뭐 했어요?`로 통일한다.
- 활동은 직전 완료된 한 시간 구간을 가리키고 실제 응답 시각은 별도로 저장한다.
- 응답이 없는 구간을 추측으로 채우지 않는다. `미기록`과 사용자가 선택한 `건너뛰기`를 구분한다.
- 홈의 중심은 감성적인 하루 카드다.
- 하단 일정표 탭에서 시간순 원본 기록과 비어 있는 시간을 확인한다.
- 초기 데이터는 계정이나 서버 없이 기기의 SQLite 데이터베이스에만 저장한다.
- 활동 기록 알림은 기본적으로 오전 9시부터 오후 10시까지 매시 정각에 예약하고, 사용자가 30분·1시간·2시간 간격과 시작·종료 시간을 바꿀 수 있다.
- 알림 권한은 앱 시작과 동시에 요구하지 않고, 설정 화면에서 용도를 설명한 뒤 요청한다.
- Android 정확 알람 권한은 요구하지 않는다. 절전 정책으로 인해 도착이 조금 늦을 수 있음을 알린다.
- 하루는 오전 4시에 바뀌며, 지난 날짜의 카드와 시간표도 같은 경계를 사용한다.
- 공유 카드는 9:16 이미지이고 시간과 메모는 기본 비공개다. 사용자가 공유 직전에 표시 여부와 제외할 장면을 고른다.
- 사진 권한은 카드 저장을 누를 때만 요청한다. 시스템 공유는 갤러리 저장 없이 임시 이미지로 진행한다.

## 임시 기본값

- 알림 간격: 1시간, 오전 9시–오후 10시
- 회고 시각: 오후 10시
- 하루 경계: 오전 4시
- 말투: 따뜻하고 부담 없는 `~해요`체
- 공유 카드의 개인 메모: 기본 비공개

## 나중에 결정할 내용

- 요일별 알림과 집중 시간 예외 설정
- 추가 공유 카드 템플릿과 색상 테마
- 원본 데이터 내보내기를 MVP에 포함할지
